# Course Syllabus

## About this course

This course introduces computer science through Python. Students will learn how to break problems into smaller steps, write readable programs, test their ideas, and use GitHub to track their work.

No prior programming experience is required.

## Learning goals

By the end of the course, students should be able to:

- Explain how programs store data and make decisions.
- Solve problems with conditionals, loops, functions, and data structures.
- Read error messages and debug programs systematically.
- Read from files and work with APIs and JSON.
- Write and run automated tests.
- Use Git and GitHub to manage code.
- Plan, build, and present a complete Python project.

## Weekly routine

Each week includes:

1. Learning objectives and lesson notes
2. Instructor-led examples
3. In-class exercises
4. An independent assignment
5. Optional resources for additional practice

## Expectations

- Attend class prepared and participate in exercises.
- Ask questions when something is unclear.
- Write your own code and credit outside sources.
- Make small, descriptive Git commits as you work.
- Treat classmates and their work with respect.

## Getting help

When asking for help, share:

1. What you expected the program to do
2. What actually happened
3. The complete error message
4. What you already tried
