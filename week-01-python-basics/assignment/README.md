# Week 1 Assignment — Introduce Yourself

Create a short Python program that introduces you to the class.

## Requirements

Your program must:

- Display your name.
- Display at least three facts about you.
- Display one goal you have for this course.
- Include at least two useful comments.
- Run without errors.

Start with [`starter.py`](starter.py).

## Run your program

From the repository root:

```bash
python week-01-python-basics/assignment/starter.py
```

## Before submitting

- Run the program one final time.
- Check spelling and output formatting.
- Confirm every `TODO` has been completed.
- Commit your work with a descriptive message.

Submission instructions will be provided in class.
