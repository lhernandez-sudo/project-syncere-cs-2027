PROJECT SYNCERE - WINDOWS SETUP
================================

1. Connect the computer to the internet.
2. Extract every file from the ZIP. Do not run setup inside the ZIP.
3. Open the extracted folder and double-click Start-Setup.bat.
4. Approve any Windows installation prompts.
5. Keep the window open until it reports success or an error.
6. If there is an error, show the open window to your instructor.

The setup installs Python, Git, Visual Studio Code, and the VS Code Python
extension. It downloads the course into Documents, creates its Python
environment, verifies it, and opens it in Visual Studio Code.
