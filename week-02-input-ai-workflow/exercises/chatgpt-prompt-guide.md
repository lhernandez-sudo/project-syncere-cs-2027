# ChatGPT Prompt Guide

Use ChatGPT as a coding partner. You remain responsible for understanding and testing the result.

## Prompt pattern

```text
Goal:
Help me add this feature to my beginner Python app: [describe your idea].

Current code:
[Paste only the relevant part of your Python file.]

Boundaries:
Keep the current choices working.
Use only input, variables, print, if, elif, and else.
Explain each changed line in beginner-friendly language.

Verification:
Give me three inputs to test after I make the change.
```

## Before accepting an answer

1. Read the response before copying anything.
2. Identify which lines will change.
3. Predict what the program will do.
4. Make the smallest useful edit.
5. Run every test case.
6. Ask a follow-up question when you cannot explain a line.

## Useful requests

- Explain this error without rewriting my whole program.
- Suggest three test cases for this choice.
- Help me reject blank input.
- Show the smallest change that adds a second ending.
- Review this code for a bug and tell me how to reproduce it.

Do not share passwords, private student information, API keys, or access tokens.
