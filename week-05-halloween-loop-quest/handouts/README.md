# Python Field Guide printing instructions

Use `python-field-guide-print-booklet.pdf` for printing.

1. Print on US Letter paper at actual size or 100 percent scale.
2. Print double-sided.
3. Flip on the short edge.
4. Keep the PDF page order unchanged.
5. Stack the two sheets, fold them together down the center, and staple twice along the fold.

The PDF is already imposed in booklet order. Do not turn on the printer's booklet rearrangement option.

The editable Word file uses one half-letter page per guide page. It is intended for content revisions, not direct booklet printing.
