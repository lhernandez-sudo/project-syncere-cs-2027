# Python Field Guide PDF

Use [`python-field-guide-print-booklet.pdf`](python-field-guide-print-booklet.pdf) for the 18 student copies.

- Print on US Letter paper at actual size or 100 percent scale.
- Print double-sided and flip on the short edge.
- Keep the existing page order.
- Do not enable the printer's booklet rearrangement option.
- Fold each booklet down the center and staple twice along the fold.

The PDF is formatted for black ink. The editable Word source and build script are in [`../handouts/`](../handouts/).
